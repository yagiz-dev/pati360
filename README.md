# Pati360

An open-source veterinary practice information system (PIMS).

I believe the best way to excel is by building things. The backend will be written in Java using Spring Boot. I will then build a frontend in Angular.

## Planned core features
* Patient and owner records, vaccination logs, prescriptions, etc.
* Appointment scheduling with collision detection for the veterinarians and practice room
* Reminders. I may even integrate WhatsApp Business API for the sake of using it
* Billing and invoicing
* Storing lab and imaging records
* Inventory management
